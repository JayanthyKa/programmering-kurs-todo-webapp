NestTask - a comfortable home for your tasks

website/      Ready to open: double-click website/index.html in any browser (Chrome, Edge, Firefox, Safari).
              index.html = page, assets/*.css = styles, assets/*.js = app logic, images/ = logo and icons.
source-code/  The original project (React + TypeScript + Tailwind CSS, TanStack Start).
              Run it:  install Bun or Node, then   bun install   and   bun run dev
              Main files: src/routes/ (screens), src/styles.css (design), src/lib/ (tasks + themes).
